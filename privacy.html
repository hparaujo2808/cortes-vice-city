Privacy Policy

Last updated: November 18, 2026

  • Data accessed. When the owner connects their own TikTok account, the tool receives basic profile information (open ID, display name, avatar) and an access token, used only to upload the owner's videos to that account's drafts.
  • Storage. The token and profile data are stored only on the owner's computer. Nothing is sent to any server other than TikTok's own API.
  • Other people. The tool does not collect, store or process personal data of any other TikTok user or viewer.
  • Sharing. No data is sold, shared or used for advertising.
  • Deletion. The owner can revoke access at any time in TikTok (Settings and privacy > Security > Manage app permissions), which invalidates the token; local files can be deleted at any time.
  • Contact. Open an issue in this site's GitHub repository.

Política de Privacidade

  • Dados acessados. Quando o dono conecta a própria conta do TikTok, a ferramenta recebe informações básicas do perfil (open ID, nome de exibição, avatar) e um token de acesso, usados apenas para enviar os vídeos do dono aos rascunhos dessa conta.
  • Armazenamento. O token e os dados do perfil ficam guardados apenas no computador do dono. Nada é enviado a nenhum servidor além da própria API do TikTok.
  • Outras pessoas. A ferramenta não coleta, guarda nem processa dados pessoais de nenhum outro usuário ou espectador do TikTok.
  • Compartilhamento. Nenhum dado é vendido, compartilhado ou usado para publicidade.
  • Exclusão. O dono pode revogar o acesso a qualquer momento no TikTok (Configurações e privacidade > Segurança > Gerenciar permissões de apps), o que invalida o token; os arquivos locais podem ser apagados quando quiser.
  • Contato. Abra uma issue no repositório do GitHub deste site.
